# Changelog

## 1.0.0 — 2026-10-10

- Release the portable C++17 simulation library and CLI.
- Implement deterministic price-time matching, partial fills, inclusive expiry, and self-trade prevention.
- Normalize basket instruments and reject invalid, ambiguous, or oversized input.
- Analyze final cross-market quote snapshots with liquidity, fee, and age limits.
- Add integer-cent accounting and structured JSON execution reports.
- Add an offline interactive session report and synthetic demo datasets.
- Add randomized reference comparisons, regression tests, and cross-platform CI configuration.
- Add a reproducible source export with checksums and preserved license notices.
